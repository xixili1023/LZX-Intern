# Personal Quant Research Assistant Skills

此目录存放 LZX-Intern 工作空间级 Codex 技能。技能用于规范后续研究工作流，不包含具体项目内容，也不会自行执行项目操作。

## Skills

| Skill | 作用 |
| --- | --- |
| `create-project` | 从标准模板创建新的量化研究项目骨架。 |
| `research-document` | 维护研究问题、框架、方法、决策与双向链接。 |
| `data-processing` | 设计并记录可复现的数据处理与质量检查流程。 |
| `factor-research` | 组织因子定义、构建、评价与证据链。 |
| `backtest` | 设计、记录或审查可复现的回测流程。 |
| `report-generation` | 基于项目证据生成研究、实习或面试输出。 |
| `git-assistant` | 生成中文为主的 Commit 标题、修改摘要和修改目的，不执行 Git 操作。 |

## 命名说明

Codex 技能目录必须使用小写字母、数字和连字符，因此需求中的下划线名称已规范化为连字符形式。

## 当前范围

- 每个技能包含必需的 `SKILL.md`。
- `agents/openai.yaml` 提供技能列表所需的轻量 UI 元数据。
- 暂未添加脚本、参考资料或资产。
- 技能只有在相关请求触发时才用于指导工作。
- `git-assistant` 只生成 Commit 说明；commit 和 push 始终由用户手动执行。
