## 当前研究边界

1. 所有横向数字统一截止到 2026-08-05，与公众号原文分析日一致。
2. 主数据使用 `Index_Daily` 中的实际更新日点位；手工表共同日期点位仅有两位小数舍入差，证明同源。
3. 手工表额外包含休市或仅部分指数更新的日期。用它直接算日频波动会加入 0 收益，因此它只用于对账，不作为日频风险主表。
4. 报告把 Wind 发布日前的历史称作“发布前回溯期”，把发布日后的历史称作“发布后运行期”。这比直接称“样本内/样本外”更严谨，因为没有正式方法书时无法确认参数训练边界。
5. CI011800 有 11 个成分快照，但 196 条权重全部为空；其余三只没有成分权重。因此可以做指数层绩效和稳定性，不能做真实资产贡献、风险贡献或完整策略复现。
6. 四只指数混有价格指数与全收益指数，收益排序不具完全同口径可比性。
7. `Product_Info` 中包含“公开新闻/RAG”而非纯 Wind 字段，`Underlying_Daily` 又有明显截断；这两张表只作为补数线索，不直接支撑费用、跟踪误差或归因结论。
8. 公众号复现先固定合理口径网格，再比较最近值；不通过任意移动起止日反向拟合原文。逐项最近方法和全文统一方法分别写入 `results/公众号口径敏感性.csv` 与 `results/公众号统一口径检验.csv`。
9. 压力窗口同时报告期末收益和窗口内最大回撤；年度集中度把最佳年份收益机械设为0，仅作为描述性反事实。
10. 新版29只指数工作簿包含28个Wind代码：CALLW.WI有完整行情并进入比较；CALLWE.WI按公众号作为另一只停更且无数据的指数保留。生成程序会补回CALLWE占位，但绝不会复制CALLW行情。

`scripts/client.py` 导入 `DataAPI`，由 `ANEMOI_GATEWAY_URL` 与 `ANEMOI_GATEWAY_KEY`
访问 Tailscale 内网网关。**不安装 `uqer`、不使用通联 token。**

运行：

`/Users/lizhexi/Desktop/LZX-Intern/.venv/bin/python scripts/uqer_supplement.py`

查询结果写入 `results/UQER查询审计.csv` 与 `results/uqer/`。
只有网关成功返回空表时才可记为“空结果”；连接失败不等于 UQER 无覆盖。

2026-08-13 实际复查：同一网关的沪深300对照查询成功返回3行；四只
目标指数的代码、全称、日行情、历史成分和权重共36项查询均返回空表。
宽松名称/旧名搜索返回的候选在名称、发布机构、基日或发布日上与目标不一致，
已排除为直接映射。因此 UQER 无法为这四只 Wind 策略指数补充目前缺失的
成分和权重。

本项目的核心不是给四只指数排一个漂亮名次，而是回答：发布前曲线有多少证据含量、发布后表现是否稳健、好业绩能否由透明规则与真实产品复制。
