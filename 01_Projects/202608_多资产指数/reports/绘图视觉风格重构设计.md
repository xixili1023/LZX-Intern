# 绘图视觉风格重构设计

## 目标

将答辩重构目录中的12张Matplotlib图统一为专业金融研究报告风格。只调整视觉系统，不改变原始数据、指标公式、图表含义、Markdown结构和结论。

## 统一主题

所有图表通过同一个 `configure_charts()` 主题和绘图辅助函数控制，不逐图重复设置基础风格。

| 元素 | 统一规则 |
| --- | --- |
| Figure背景 | 纯白 `#FFFFFF` |
| Axes背景 | 近白灰 `#FAFAFA`，不得明显偏黄 |
| 正文颜色 | 深灰蓝 `#26333D` |
| 网格 | 浅灰细线，默认只在主要读数方向显示，透明度约0.20 |
| 边框 | 隐藏上、右边框；左、下边框使用浅灰细线 |
| 标题 | 左对齐、克制字号、靠近绘图区 |
| 图例 | 无边框、紧凑、不遮挡数据 |
| 数据来源 | 图底部小号灰字“数据来源：Wind” |
| 保存背景 | 强制白色、不透明 |

## 配色系统

使用低饱和金融研报配色：深蓝、蓝绿色、暗红、灰紫和蓝灰。橙色仅作少量辅助强调。

- 深蓝：主要数据与发布后运行期；
- 蓝灰/中性灰：对照数据与发布前回溯期；
- 暗红：收益衰减、过拟合担忧或唯一重点；
- 蓝绿色、灰紫：多序列区分；
- 暗金橙：仅在第三类或阈值辅助中少量使用。

同一类别的柱子优先使用同一蓝灰色系，只对需要强调的柱子使用暗红色。多序列折线保持相同线宽，不使用荧光色、渐变、阴影或大面积装饰性色块。

## 图表级调整

1. 样本状态图：前三根柱使用蓝灰色的不同深浅，统一口径可复算使用暗红强调。
2. 全景判断图：公众号分组使用蓝灰体系；统一复算中仅收益衰减组使用暗红，其余使用蓝灰/蓝绿。
3. 发布前后哑铃图：发布前为中性灰，发布后为深蓝。
4. 衰减排行：主体使用深蓝或蓝灰，超过阈值的重点使用暗红；不使用大面积鲜橙。
5. 原文复算图：原文为中性灰，统一复算为深蓝。
6. 四指数与四张个案图：使用固定的低饱和四色；发布前为中性灰，发布后使用指数固定色。
7. 夏普—衰减散点图：过拟合担忧使用暗红，基本一致使用蓝灰，样本外更好使用蓝绿；趋势线为深灰虚线。

## 实现边界

- 保留12张PNG的文件名和Markdown引用路径；
- PNG仍只包含标题、图表、必要图例/标记和数据来源；
- 不修改指标口径、样本分类、结论文字或表格数据；
- 不增加渐变、阴影、3D、发光、装饰边框或PPT信息图元素。

## 验证标准

1. 自动测试锁定Figure背景、Axes背景、保存背景、图例和边框的全局参数；
2. 重新生成12张PNG并检查图片四角为纯白色；
3. 抽查柱状图、哑铃图、多序列折线图、个案图和散点图；
4. 运行完整测试套件并验证Markdown仍引用12张有效图片。
