# 券商多资产配置指数答辩重构设计

## 目标

围绕公众号《券商多资产配置指数深度体检报告：样本内的魔术 vs 样本外的现实——29只指数的过拟合真相》，用最新版 Wind 工作簿复现文章逻辑、补充四只重点指数证据，并形成可直接投屏的 Markdown 答辩材料。

## 展示格式修订（2026-08-16）

- Python 生成的 PNG 只保留：图表题目、坐标轴、数据图形、必要图例/发布日标记和“数据来源：Wind”。
- PNG 不再包含：页面问题、口径说明、结论、评价、异常分析、证据边界、文字卡片或整页排版。
- 每页 Markdown 负责：模块标题、图片引用、Markdown 原生表格、构造方式、读图、含义、异常分析与证据边界。
- 29 只完整指标表和四只重点指数指标表全部改为 Markdown 原生表格，不再生成表格 PNG。
- 筛选方法、过拟合原因和最终评价如果没有实质统计图，直接使用 Markdown 文字页，不为了排版制作 PNG。

## 交付物

- 一个独立 Python 脚本：`scripts/build_29_index_deck.py`。
- 支撑结果：写入现有 `results/`，文件名前缀统一为 `答辩重构_`。
- 新图片：写入 `figures/答辩重构/`，不覆盖既有图片。
- 新 Markdown：`reports/券商多资产配置指数_重构版.md`，不覆盖用户手工修改的旧报告。

## 研究主线

汇报严格对应带教提出的四项要求：

1. 第一部分交代公众号的关键词筛选、资产类别验证、排除标准和 29 只指数全景。
2. 29 只指数进入统一指标表和一句话评价；四只重点指数另做横向总表和完整个案页。
3. 分析多资产策略容易过拟合的原因，并用 29 只指数复算结果检验文章主张。
4. 把已确认的统计放入全景表、四指数个案和公众号数字复核页。

评价公众号不替代上述结构，而是贯穿每一部分：公众号怎么说、Wind 数据复现了什么、我们怎样评价。

## 数据与口径

- 主数据：`data/29只券商多资产配置指数_原始数据.xlsx`。
- 截止日：2026-08-05，与公众号原文分析日一致。
- 发布前回溯期与发布后运行期共享最后一个不晚于发布日期的有效锚点。
- 年化收益：实际日历时间 CAGR。
- 年化波动：日收益样本标准差乘以 `sqrt(252)`。
- 夏普：日频、`sqrt(252)`、年化无风险利率 1.5%。
- 最大回撤：区间内点位相对历史峰值的最小跌幅。
- 空收盘价与重复代码—日期删除。
- 对已标记“停更后前向填充”的序列，保留终端平坦区间首点，删除其后重复值。
- 价格指数与全收益指数保留收益类型标识，不表述为完全公平的策略能力排名。

## 分类与评价

主汇报沿用公众号逻辑，不另建复杂评级：

- 数据情况：有发布前后对比、无发布前回溯、停更或数据不足。
- 公众号判断：样本外更好、基本一致、过拟合、严重过拟合、不判断。

统一复算结果不直接证明因果过拟合。样本过短、停更、市场环境、收益类型、规则变化和产品成本作为评价边界写入相关页面。

## 图片设计

主汇报只生成12张“纯图表PNG”：

1. 29只样本与数据状态；
2. 29只全景判断分布；
3. 发布前后年化收益比较；
4. 发布前后夏普比较；
5. 收益衰减排行；
6. 公众号原文与统一复算；
7. 四只重点指数全历史走势；
8—11. 四只重点指数各自的纯走势图；
12. 发布前夏普与发布后收益衰减散点图。

筛选方法、过拟合原因和最终评价使用 Markdown 文字页。29只完整指标表使用三页 Markdown 原生表格。四只个案页中的统一指标、资产与发行材料、公众号观点、复算结果、最终理解和证据边界全部由 Markdown 承载。

## Markdown 结构

最终 Markdown 使用 `---` 分页，顺序为：

1. 封面；
2. 筛选方法与标准；
3. 29 只样本和数据状态；
4. 29 只全景总览；
5. 发布前后收益；
6. 发布前后夏普；
7. 收益衰减排行；
8. 公众号原文与统一复算；
9. 四只指数横向比较；
10—13. 四只重点指数个案；
14. 多资产策略为何容易过拟合（Markdown文字）；
15. 29 只指数是否支持文章主张（纯散点图+解读）；
16. 最终评价（Markdown文字）；
17—19. 29 只完整指标表（Markdown原生表格）。

## 验收标准

- 29 只指数全部出现在全景结果和附录表中。
- 四只重点指数均有统一模板个案页。
- 停更后的重复点位不进入正式绩效计算。
- 没有发布前回溯段的指数不虚构前后差。
- 文章原文、统一复算和项目评价明确分开。
- 所有PNG使用 PingFang SC、可投屏，且只包含图题、图形必要元素和“数据来源：Wind”。
- 所有表格均为 Markdown 原生表格，不生成表格PNG。
- Markdown 中的图片路径全部存在。
- 单脚本可重复生成全部 CSV、图片和 Markdown。
- 不修改原始工作簿，不覆盖旧脚本、旧图片和旧 Markdown。
