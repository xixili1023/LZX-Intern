# 项目背景

高频期货价格在很短时间尺度内受到盘口深度、买卖力量、订单流变化和市场状态影响。本项目希望利用半秒级快照中的微观结构信息，判断未来几秒价格向哪一侧偏移以及偏移强度。

课程项目选择铜期货合约 `CU2311`，研究数据集中在 2023-10-16 至 2023-10-31。研究同时覆盖预测误差和交易结果，尝试回答“统计预测能力是否能够转化为扣除成本后的交易信号”。

代码审查确认，`last_price` 本身未直接进入模型，但 `D_k`、`effective_spread` 以及部分 `avg_price` 记录依赖当前 `last_price`。订单簿中的 `last_price` 依赖当前时刻成交结果；相对于仅使用盘口形成信号的决策时点，它属于包含未来成交信息的价格变量，可能导致模型提前获得未来信息。这是下一阶段代码审查需要优先确认的问题。
