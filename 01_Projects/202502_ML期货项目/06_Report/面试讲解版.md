# ML 期货高频预测项目：面试讲解版

> 定位：3–5 分钟项目介绍。项目由团队共同完成，当前不展示具体模型或回测指标。

## 一句话介绍

这是一个由团队共同完成的铜期货高频预测课程项目。项目使用半秒级五档盘口构造市场微观结构特征，比较多类机器学习模型，并将预测结果放入考虑滑点和手续费的回测框架。

## 1. 项目背景

项目希望研究当前盘口中的买卖深度、订单不平衡和订单流变化，能否预测未来几秒的价格变化。

代码使用 FastBox 的 `CU2311` 半秒级快照，正式标签是未来 6 个快照后的 `last_price return`，即未来 3 秒收益。

## 2. 团队工作内容

项目的数据清洗、特征工程、模型训练、回测框架和交易成本敏感性分析均由团队共同完成，不区分个人贡献。

## 3. 特征工程

根据现有 Notebook，可以确认的特征主要包括：

- mid-price、买卖价差和相对价差；
- 五档盘口深度、OBI、SOIR 和市场压力；
- 相邻快照变化形成的多档 OFI；
- 用于描述盘口量持续性的滚动 Hurst。

SMA、EMA、VWAP 和已实现波动率在代码中未找到实现，因此不会作为已完成特征介绍。

## 4. 模型选择

现有代码形成独立流程的核心模型是 Ridge、RBF-SVR、单棵 Decision Tree 和 LightGBM。

Linear Regression、Lasso 和 Random Forest 没有形成独立实验：

- Linear Regression 没有独立训练代码；
- Lasso 仅作为注释候选；
- Random Forest 没有实现，现有树模型是单棵 Decision Tree。

## 5. LightGBM 理解

项目使用 Python 的 `lgb.train` 调用 LightGBM。

训练数据先封装为 `lgb.Dataset`，然后由 LightGBM 使用直方图算法寻找分裂点，并采用 Leaf-wise 策略生长决策树。模型通过 GBDT 逐轮增加树来修正预测误差，最后将多棵树的输出组合成收益预测。

实际代码使用 `learning_rate=0.01`、`num_leaves=31` 和最多 100 轮 Boosting，并使用 Early Stopping。代码没有设置 `max_depth`。

## 6. 回测框架

回测将预测收益与正负阈值比较，生成多头、空头或空仓信号。信号延迟一个快照形成仓位，然后根据仓位变化扣除滑点和手续费，并计算累计收益、Sharpe 和最大回撤。

具体结果暂不整理，仍保留在原 Notebook 输出中。

## 7. 主要问题

代码审查确认，`last_price` 本身没有直接进入模型，因为特征切片排除了该列。但是 `D_k`、`effective_spread` 和部分 `avg_price` 记录依赖当前 `last_price`。

订单簿中的 `last_price` 依赖当前时刻成交结果；相对于仅使用盘口形成信号的决策时点，它属于包含未来成交信息的价格变量，可能导致模型提前获得未来信息。

此外，LightGBM 的一部分验证使用随机 KFold，另一个版本在 Early Stopping 中使用测试集，这些问题都会影响结果可信度。
