# 数据字段

以下字段来自原始 Markdown 和 Notebook 中实际引用。完整数据字典仍需根据 FastBox 返回结果确认。

## 标识与时间

| 字段 | 含义 |
| --- | --- |
| `instrumentid` | 期货合约标识 |
| `trade_time` | 快照时间戳 |

## 成交与行情

| 字段 | 含义 |
| --- | --- |
| `last_price` | 最新成交价 |
| `avg_price` | 平均成交价格；代码中存在合约乘数调整 |
| `vol` | 成交量字段 |
| `open` | 开盘价 |
| `highest` | 最高价 |
| `lowest` | 最低价 |
| `up_limit` | 涨停价格 |
| `dn_limit` | 跌停价格 |

## 五档盘口

| 字段组 | 含义 |
| --- | --- |
| `pb1`–`pb5` | 买一至买五价格 |
| `pa1`–`pa5` | 卖一至卖五价格 |
| `vb1`–`vb5` | 买一至买五挂单量 |
| `va1`–`va5` | 卖一至卖五挂单量 |

## 派生字段

- `mid_price`：买一价与卖一价的均值。
- `spread`、`relative_spread`：绝对与相对买卖价差。
- `bid_depth`、`ask_depth`、`total_depth`：盘口深度。
- `order_imbalance`、`SOIR`、`OFI` 等：盘口和订单流特征。
- `D_k`：使用 `last_price` 相对一档中间价的位置判断成交方向。
- `effective_spread`：使用 `last_price` 与 `mid_price_t` 构造的有效价差。
- `return`：训练代码中由 `last_price.shift(-6)` 构造的未来 3 秒收益标签。
