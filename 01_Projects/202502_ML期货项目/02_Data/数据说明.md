# 数据说明

## 数据来源

- 平台：FastBox 期货数据平台。
- 数据类型：半秒级期货 Level-2 盘口快照。
- 合约：铜期货 `CU2311`。
- 代码请求区间：2023-10-16 至 2023-10-31。

## 数据用途

- 构建价格、盘口、订单流和市场状态特征。
- 构造未来 3 秒收益标签。
- 划分训练集和测试集。
- 支持模型评价和策略回测。

## 数据存储

`features.pkl` 来源于已有数据处理流程，随后由当前 Notebook 继续完成标准化和训练测试集划分。`features.pkl`、`Train_data.pkl`、`Test_data.pkl` 及 FastBox 原始数据均不随 Git 提交。
