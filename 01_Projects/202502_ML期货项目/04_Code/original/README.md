# Original Notebooks

本目录保存课程项目 Notebook 的冻结副本，用于追溯原始研究逻辑、既有输出和迁移起点。

## 文件

- `ML1_homework.ipynb`：原始数据处理与特征工程。
- `Modeling.ipynb`：原始模型训练。
- `Modeling_Backtest.ipynb`：原始回测与策略评价。

## 使用规则

- 不在本目录直接修改代码、Markdown 或已有输出。
- 研究级调整统一在 [[../revised/README|revised]] 中进行。
- 本目录文件与职责分类目录中的原 Notebook 保持逐字节一致；职责分类目录暂时保留，以兼容已有 Obsidian 链接。
- 原 Notebook 的结果只代表原课程流程，不因 revised 代码生成而自动获得新的有效性结论。
