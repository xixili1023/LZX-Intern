# Projects

这是 Portfolio 的核心目录，每项量化研究经历或策略研究都应作为独立项目保存在这里。

## 目录作用

每个项目独立维护：

- 项目介绍与个人贡献
- 研究问题、逻辑与方法
- 数据说明与处理流程
- 因子或模型设计
- 回测框架与参数
- 项目代码
- 实验记录
- 完整报告与展示版本

## 使用方式

从 [[03_Templates/Project_Template/README|Project Template]] 复制完整项目骨架到本目录，然后重命名。不要直接在模板目录中开展研究。

## 项目索引

- [[00_Home/项目数据库|项目数据库]]：查看项目状态与当前阶段
- [[00_Home/项目索引|项目索引]]：浏览全部项目入口
- [[00_Home/当前任务|项目进展与下一步]]：查看已完成里程碑、正在进行和下一阶段

项目状态只在各项目的 `PROJECT_STATUS.md` 维护，不在本页重复分类。
