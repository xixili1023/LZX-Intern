# 我的贡献

## 工作范围

原始材料表述为：在实习期间完整参与以下研究与回测环节：

- 数据清洗
- 龙头股筛选
- 量价因子构建
- 行业景气度建模
- IC 分析
- 多因子组合
- 交易回测
- 对冲评估

## 核心工作内容

- 以行业指数和行业成分股为基础构建研究对象。
- 设计动态龙头股筛选与行业缺失时的捏合股兜底机制。
- 研究多尺度动量因子，并通过 IC、纯多头回测和相关性分析筛选因子。
- 整理 Wind EDB 行业景气指标，设计不同类型指标的预处理方法。
- 使用 TS-IC 评价行业景气指标，并构建行业景气度组合信号。
- 比较景气度的 gate、weight 和 tilt 三种使用方式。
- 在日频回测中加入换手成本，并评估相对宽基指数的表现。
