# Project Profile

## 文件夹用途

作为项目身份卡和 Portfolio 入口，回答“项目是什么、为什么做、由谁完成、何时推进”。

## 应该存放什么

- `项目简介.md`：目标、范围、状态和交付物概览
- `项目背景.md`：业务、市场或研究背景
- `我的贡献.md`：个人职责、关键决策和可核验产出
- `项目时间线.md`：阶段、里程碑、变更和进度

## 不应该存放什么

- 详细方法推导或实验结果
- 源代码、数据文件和回测产物
- 与个人贡献无关的泛化表述
- 无法链接到研究证据的成果描述

## 与其他模块的关系

- 为 [[01_Research/README|Research]] 定义目标和边界。
- 汇总 [[06_Experiment/README|Experiment]] 与 [[07_Report/README|Report]] 的关键进展。
- `我的贡献.md` 应链接到对应代码、实验、研究文档或报告。
