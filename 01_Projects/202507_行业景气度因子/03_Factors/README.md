# Factors

## 文件夹用途

管理因子的经济逻辑、定义、构建流程、评价方法和研究结论。

## 应该存放什么

- `因子说明.md`：因子定义、类别、预期方向和经济含义
- `因子构建.md`：计算公式、预处理、后处理和版本
- `因子评价.md`：有效性、稳定性、独立性和可交易性评价
- 因子假设、口径变更和评价结论

## 不应该存放什么

- 因子实现源代码或运行环境
- 未解释来源的最终信号文件
- 只展示最佳结果、缺少完整评价的记录
- 与项目无关的公共因子资料

## 与其他模块的关系

- 因子设计来源于 [[01_Research/README|Research]] 的问题与假设。
- 输入数据由 [[02_Data/README|Data]] 定义。
- 实现代码位于 [[05_Code/README|Code]] 的 `factor/`。
- 因子通过 [[04_Backtest/README|Backtest]] 和 [[06_Experiment/README|Experiment]] 评价。
- 最终逻辑和证据汇总到 [[07_Report/README|Report]]。
