# Factors

## 模块说明

本模块用于管理行业轮动研究框架中的因子定义、研究逻辑、构建方法与评价记录。

本项目当前包含：

- [[01_行业景气度因子/因子说明|行业景气度因子]]：刻画中观基本面、产业周期和宏观变量所反映的中长期行业方向。
- [[02_动量因子/因子说明|动量因子]]：刻画不同时间尺度下的价格趋势、相对强弱和路径平滑程度。
- [[03_多因子组合/组合逻辑|多因子组合框架]]：用于后续记录因子组合逻辑与[[03_多因子组合/权重设计|权重设计]]，当前仅建立框架。

## 内容边界

本模块保存因子研究文档，不保存：

- 因子实现代码；
- 原始数据或加工数据；
- 回测结果；
- 未经记录支持的评价结论；
- 尚未确定的多因子权重方案。

## 与其他模块的关系

- 因子研究问题与整体框架来自 [[../01_Research/README|Research]]。
- 因子输入数据及处理口径由 [项目外部数据说明](/Users/lizhexi/Desktop/InternData/行业景气度项目Data/README.md) 管理。
- 后续实现代码应放入 [[../04_Code/README|Code]]。
- 因子评价应以 [[../03_Backtest/README|Backtest]] 与 [[../05_Experiment/README|Experiment]] 中可追溯的证据为基础。
- 经验证的研究结论再汇总至 [[../06_Report/README|Report]]。
