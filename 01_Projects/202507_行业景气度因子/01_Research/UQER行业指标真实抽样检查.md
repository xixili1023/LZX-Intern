# UQER 行业指标真实抽样检查

## 结论

UQER 的宏观行业接口已在当前网关环境中跑通，返回的元数据和长表观测值足以支持指标盘点、Wind 映射和历史可得性检查。但官方页面提供的示例指标只适合验证接口，不能直接当作行业景气因子输入。

本阶段的正确结论是“取数链路可用”，不是“这 24 个示例指标已经有效”。正式研究必须先建立 Wind–UQER 映射，再下载已审核指标的全历史。

## 真实返回结构

### 元数据

`EcoInfoProGet` 返回每个指标的代码、中英文名称、频率、单位、统计类型、地区、来源、起止日和更新状态等。这些字段是建立 Wind–UQER 映射的主依据，指标名称只是候选检索线索。

数值接口和元数据字段使用不同名称。例如：

| 职责 | 化工接口名 |
| --- | --- |
| 历史观测请求 | `EcoDataIndChemicalGet` |
| `EcoInfoProGet.dataApiName` 过滤值 | `getEcoDataIndChemical` |

如果把前者直接传给 `dataApiName`，元数据返回为空。两个名称已分别记录在接口清单中。

### 观测值

每条原始观测至少有：

| 字段 | 研究含义 |
| --- | --- |
| `indicID` | 指标主键 |
| `periodDate` | 数值所属统计期，不是默认可用日 |
| `publishDate` | 数据发布时间，是构造无前视信号的首选字段 |
| `dataValue` | 接口返回的原始值，结合元数据单位解读 |
| `updateTime` | UQER 数据库更新时间，可反映修订或入库，不默认等于首次发布 |

## 为什么不直接全量下载

2026-08-07 实测 `getEcoDataIndChemical` 单一 API 元数据就返回约 93,979 行。如果直接将这些指标的全历史全部下载，会带来大量无关请求、流量消耗和后续小文件。

因此采用三阶段结构：

1. `sample`：用示例代码验证连通、字段、类型和日期语义。
2. `metadata`：只对目标 API 下载元数据，生成 Wind–UQER 候选映射。
3. `selected`：仅对人工审核通过的指标下载全历史观测。

代码上使用一个配置驱动的下载器，而不是每个指标一个 Python 文件。原始数据按 `API × 请求批次` 保存，既能减少请求，也能在单一批次失败时准确重跑。

## 与旧 Wind 数据如何判断一致

参考 [[UQER与Wind景气指标对账方案|UQER 与 Wind 景气指标对账方案]]，一致性必须拆成三层。

### 1. 元数据是否同口径

逐项检查统计对象、当期/累计/同比/环比口径、频率、单位、地区、来源、季调和价格类型。名称相似但船型、品种、地区或统计方式不同的指标，只能记为 `near` 或 `pending`。

### 2. 原始数值和可用时点是否一致

UQER 使用 `periodDate` 表示统计期，使用 `publishDate` 表示发布时间。旧 Wind 宽表已向后填充，却没有独立发布日和统计期，因此不能做完美的 point-in-time 历史复原。

可执行的对账方式是：

1. 先根据元数据明确单位倍率和口径，不使用回归自动“拟合”单位。
2. 在 UQER 的 `publishDate` 或已核准代理日生成 as-of 序列，向交易日展开。
3. 将旧 Wind 宽表的数值变化日当作近似更新事件，比较数值、变化方向、缺失段和更新日差。
4. 对同统计期计算绝对误差、相对误差、Pearson/Spearman 相关和方向一致率，但不用任一单一相关阈值自动判定同口径。
5. 数值差异必须能由展示精度、单位、修订版本或日期归属解释，否则不标记为 `exact`。

### 3. 处理后信号是否可替代

对 `exact` 和 `near` 分开测试，使用相同的变换、滞后、标准化和未来行业收益标签，比较处理后信号相关、TS-IC、ICIR、方向稳定性、聚合后行业得分和策略结果。高相关可以支持“研究上近似替代”，但不能反向证明原始数据完全一致。

## 当前已知限制

- 2,786 行抽样中有 760 行缺少 `publishDate`；这些指标必须找到可验证的发布规则，否则不进入严格无前视因子。
- `publishDate` 可早于月末标签 `periodDate`；这可能是月份归属，不能通过简单的“负滞后”规则全部判错。
- `updateTime` 可能反映数据库修订；除非得到外部证据，不得将它静默替代 `publishDate`。
- UQER 历史值可能是修订后终值；若接口不提供历史版本，修订偏差必须进入研究限制。
- 原 Wind 宽表与抽样 UQER 的指标名称没有精确重合，这只说明示例代码不是旧指标映射，不能据此说 UQER 无对应数据。

## 下一步

1. 对与旧 318 个 Wind 代码相关的 API 只下载元数据，生成候选集。
2. 先选取价格、产量当期值、累计值、同比/比率和指数各若干条，完成 10–20 个人工映射样本。
3. 只对映射为 `exact` 或经审核的 `near` 指标下载 `2015-01-01` 以来历史值。
4. 在重叠期执行数值与可用时点对账，冻结第一版 crosswalk。
5. 映射冻结后再开始景气指标转换、TS-IC 和行业内聚合，不在当前抽样上做因子有效性结论。
