# 行业景气度因子项目建设路线图

## 总结

本项目从确定研究口径开始，先确认并获取行情数据与 UQER 行业景气指标，再完成数据对齐、研究对象构建、景气度因子和动量因子研究。因子通过检验后进入单因子回测、多因子组合、样本外验证，最后整理为可复现和可持续更新的研究项目。

P2A 与 P2B 可以并行进行；其余阶段原则上按顺序推进。每完成一个阶段，再勾选目录中的对应项目并进入下一阶段。

## 阶段目录

1. [ ] **P0：确定研究口径**——固定研究对象、样本、标签、交易时点和评价方式。
2. [ ] **P1：确认数据源与字段**——确认公司数据库和 UQER 能提供哪些数据。
3. [ ] **P2A：获取行情与行业数据**——下载股票、行业、成分、权重和基准数据。
4. [ ] **P2B：获取 UQER 景气指标**——整理指标清单并下载原始指标数据。
5. [ ] **P3：处理并对齐数据**——生成时点正确的市场和景气指标面板。
6. [ ] **P4：构建研究对象与收益标签**——生成行业收益、未来收益和动态龙头股池。
7. [ ] **P5：构建行业景气度因子**——从行业指标生成不同期限的景气度因子。
8. [ ] **P6：构建动量与情绪因子**——实现并核验各类动量信号。
9. [ ] **P7：评价和筛选因子**——决定哪些因子进入回测。
10. [ ] **P8：搭建回测并运行单因子基线**——先验证交易时钟、成本和回测计算。
11. [ ] **P9：组合因子并运行完整回测**——比较景气度与动量的组合方式。
12. [ ] **P10：进行样本外与稳健性检验**——检查结果是否依赖特定时期或参数。
13. [ ] **P11：整理报告与复现流程**——固定研究证据、运行顺序和更新方法。

# 具体内容

## P0：确定研究口径

**这一阶段做什么**

先把研究中所有会影响数据和回测的关键口径确定下来，避免后面边写代码边改定义。

**具体怎么完成**

- [ ] 确定使用哪一版申万行业分类，以及研究行业范围。
- [ ] 确定历史研究区间、训练区间、验证区间和最终测试区间。
- [ ] 确定行业指数、动态龙头股和捏合组合分别承担什么作用。
- [ ] 确定未来收益标签，以及信号形成、下单、成交和持仓的时间顺序。
- [ ] 确定主要基准和评价指标。
- [ ] 把 `TopK`、费率、`lambda` 和因子窗口等历史参数列为待验证参数，不直接沿用。

**本阶段结束时**

研究对象、样本划分、收益标签、交易时点和评价方法已经写清，可以据此列数据需求。

## P1：确认数据源与字段

**这一阶段做什么**

确认当前环境能否提供项目所需数据，并找到对应的表、字段和访问方式。

**具体怎么完成**

- [ ] 找到股票日行情、证券基础信息、复权、停复牌和涨跌停数据。
- [ ] 找到申万行业指数、历史成分、历史权重和分类调整数据。
- [ ] 确认 VWAP 能否直接获取；不能直接获取时，确认成交额和成交量口径。
- [ ] 找到宽基指数数据，以及可能使用的行业 ETF 或其他交易载体数据。
- [ ] 登录 UQER，确认接口权限、历史覆盖、指标元数据、下载格式和限频规则。
- [ ] 从每个关键数据源读取少量样例，核对代码、日期、单位、主键和覆盖范围。

**本阶段结束时**

每项研究数据都有明确来源和字段；无法获取的项目已经列出替代方案或范围调整。

## P2A：获取行情与行业数据

**这一阶段做什么**

把股票、行业和基准数据按统一研究区间下载并保存为第一版原始快照。

**具体怎么完成**

- [ ] 下载交易日历、证券代码、上市日期、退市日期和代码变更信息。
- [ ] 下载股票 OHLCV、成交额、复权字段和 VWAP 相关字段。
- [ ] 下载行业指数行情、历史行业成分、历史权重和分类有效期。
- [ ] 下载确定使用的宽基指数行情。
- [ ] 保存查询参数、下载时间、数据区间、行数和文件位置。
- [ ] 抽查普通交易日、行业调整日、停牌日和退市股票数据。

**本阶段结束时**

原始行情和行业数据能够重新下载，文件范围和来源已经记录清楚。

## P2B：获取 UQER 景气指标

**这一阶段做什么**

把旧研究中的指标线索重新映射到 UQER，并下载可使用的原始指标数据。

**具体怎么完成**

- [ ] 根据旧 README 和现有指标清单整理候选指标。
- [ ] 为每个指标记录 UQER 代码、名称、频率、单位、统计口径和历史区间。
- [ ] 记录指标对应行业、价值链位置和可能的经济方向。
- [ ] 将指标标记为完全匹配、近似替代、暂不可得或待确认。
- [ ] 先下载少量不同类型的指标，检查分页、限频、缺失值、重复值和日期字段。
- [ ] 样例确认无误后下载全量指标，并保存原始返回结果和下载记录。

**本阶段结束时**

所有候选指标都有明确状态，可用指标已经下载，缺失指标和替代关系已经记录。

## P3：处理并对齐数据

**这一阶段做什么**

把行情和景气指标转换为字段统一、可以计算因子且不使用未来信息的数据面板。

**具体怎么完成**

- [ ] 统一证券代码、行业代码、日期格式、数据类型和单位。
- [ ] 处理重复、缺失、停牌、异常行情、复权和行业分类变化。
- [ ] 将累计值转为当期增量，将价格或价差转为变化率，并统一同比、比率、库存和开工率口径。
- [ ] 区分指标观测期、发布日期和实际可用日期。
- [ ] 在原始更新频率上完成转换，再按可用日期向交易日展开。
- [ ] 分开设置数据发布滞后和产业链传导滞后。
- [ ] 检查公布日前后、非交易日、修订日和长期缺失区间。

**本阶段结束时**

可以从任意处理后数据追溯到原始值和转换规则，任何信号日都不会使用当时尚未可见的数据。

## P4：构建研究对象与收益标签

**这一阶段做什么**

生成行业层面的研究面板、未来收益标签，以及后续选股使用的动态龙头股池。

**具体怎么完成**

- [ ] 生成每个交易日有效的申万行业列表。
- [ ] 整理官方行业指数收益；如需要行业 VWAP，则用当日成分和权重重新合成并对账。
- [ ] 生成 `20/63/126/252` 日未来行业收益标签。
- [ ] 按权重阈值、复合得分和权重 × 流动性三种方法生成龙头股候选。
- [ ] 使用评估日前历史数据计算 Tracking Error 和相关性，选择行业代表股。
- [ ] 对多个普通日和行业调整日手工回放候选生成过程。
- [ ] 明确无合格股票时使用捏合组合、空仓还是其他处理方式。

**本阶段结束时**

行业行情、未来收益和每日龙头股池可以直接提供给因子研究和回测。

## P5：构建行业景气度因子

**这一阶段做什么**

按照指标更新、转换、方向和行业映射，生成不同期限的行业景气度因子。

**具体怎么完成**

- [ ] 为每个“指标 × 行业”确认转换方法、滞后、预期方向和适用范围。
- [ ] 只在指标实际更新日生成新信号，再向后展开到交易日。
- [ ] 比较稳健 Z-score、时序秩分位等标准化方式。
- [ ] 计算指标对未来行业收益的 TS-IC、滚动 IC 和 ICIR。
- [ ] 保留经济方向等权聚合的简单基线。
- [ ] 如使用统计 IC 决定方向和筛选，只使用滚动或扩展训练窗口。
- [ ] 生成 `factor_063`、`factor_126`、`factor_252` 等候选因子版本。
- [ ] 选择少量指标、行业和日期完成手工对账。

**本阶段结束时**

得到有明确版本、计算口径和数据来源的行业景气度候选因子。

## P6：构建动量与情绪因子

**这一阶段做什么**

按照《动量因子详细描述》重新实现动量因子，并统一复权、截面和信号时间口径。

**具体怎么完成**

- [ ] 固定 5、20、60、120、252 日五个窗口，不再补充第六个窗口。
- [ ] 实现 5 日、20 日点对点动量，以及跳过最近 20 日的 60、120、252 日基础动量。
- [ ] 对基础动量分别计算截面分位数排名和截面 Z-score。
- [ ] 实现日收益率横截面 Wright 变换后取滚动均值的 Rank Momentum。
- [ ] 实现“累计收益率 ÷ 日收益率绝对值之和”的 Smooth Momentum。
- [ ] 实现当前价格在窗口最高价与最低价之间的 Position Factor。
- [ ] 区分行业层和个股层因子，分别处理截面标准化。
- [ ] 确定去极值、缺失、停牌、最小历史长度和复权规则。
- [ ] 为每类因子选择少量日期和窗口进行手工核对。

**本阶段结束时**

得到公式明确、窗口固定、能够重复计算的动量和情绪候选因子。

## P7：评价和筛选因子

**这一阶段做什么**

比较候选因子的有效性、稳定性和冗余程度，确定进入回测的因子版本。

**具体怎么完成**

- [ ] 检查每个因子的覆盖率、分布、极端值和方向稳定性。
- [ ] 对景气度因子计算 TS-IC、滚动 IC、ICIR 和分行业表现。
- [ ] 对动量因子计算 CS-IC、Rank IC、分组收益、衰减和换手。
- [ ] 比较因子相关性和增量信息，识别重复因子。
- [ ] 只用训练集开发、验证集选型，保留测试集和最终留出集。
- [ ] 记录每个因子的保留或淘汰理由，包括失败和不利结果。

**本阶段结束时**

形成进入回测的因子清单，每个因子都有版本、方向、适用区间和筛选理由。

## P8：搭建回测并运行单因子基线

**这一阶段做什么**

先确认回测时钟、持仓计算和成本扣减正确，再测试纯景气度和纯动量策略。

**具体怎么完成**

- [ ] 固定信号形成、下单、成交、持仓和收益归属顺序。
- [ ] 区分行业指数研究组合与 ETF 或成分股可交易组合。
- [ ] 用等权、恒定持仓、单资产和已知收益序列检查回测计算。
- [ ] 分别设置手续费、印花税、滑点、冲击成本和不可交易状态。
- [ ] 根据每日权重变化计算买入、卖出、换手和成本。
- [ ] 分别运行纯景气度、纯动量和简单等权基线。
- [ ] 输出收益、波动、Sharpe、最大回撤、换手、成本和相对基准表现。

**本阶段结束时**

回测引擎通过手工案例核验，并得到可以比较的单因子基线结果。

## P9：组合因子并运行完整回测

**这一阶段做什么**

比较景气度与动量的不同组合方式，确定候选的完整策略。

**具体怎么完成**

- [ ] 固定纯景气度、纯动量和简单等权组合作为对照。
- [ ] 分别测试 `gate`、`weight` 和 `industry_tilt`。
- [ ] 只在训练和验证区间选择 `lambda`、TopK、调仓频率和权重。
- [ ] 检查行业指数与其成分股是否形成重复暴露。
- [ ] 计算毛收益、净收益、换手、成本、行业暴露和收益归因。
- [ ] 保存全部参数方案，包括失败和表现不利的结果。

**本阶段结束时**

得到若干冻结参数的候选策略，并明确它们相对单因子基线的增量表现。

## P10：进行样本外与稳健性检验

**这一阶段做什么**

检查候选策略是否只在特定时间、行业、参数或成本假设下有效。

**具体怎么完成**

- [ ] 方法和参数冻结后，再运行最终留出集。
- [ ] 分年、分行业、分市场状态和分指标类型检查结果。
- [ ] 提高交易成本并加入成交延迟、不可交易和更低调仓频率。
- [ ] 改变 TopK、因子窗口、样本起止和组合参数。
- [ ] 检查完全匹配、近似替代和缺失 UQER 指标对结果的影响。
- [ ] 如财务数据可得，构造财务型行业景气度作为独立对照。
- [ ] 分析流动性、容量、行业暴露、市场 Beta 和收益来源。

**本阶段结束时**

每项主要结论都能说明适用条件，并标注为已验证、初步观察、失败结果或待验证假设。

## P11：整理报告与复现流程

**这一阶段做什么**

把研究过程、结果和更新步骤整理成可以展示、复查和继续维护的项目。

**具体怎么完成**

- [ ] 固定数据获取、校验、处理、因子、评价、回测和报告的运行顺序。
- [ ] 为正式结果记录数据版本、因子版本、参数、代码 commit 和 Experiment ID。
- [ ] 整理项目总结报告、面试讲解版和已知限制。
- [ ] 写清环境配置、运行入口和指定实验的复现方法。
- [ ] 写清 UQER 和行情数据的增量更新步骤。
- [ ] 用新数据完整执行一次更新流程，确认不会覆盖历史结果。

**本阶段结束时**

读者可以从报告追溯到数据、因子、代码和实验；研究者可以按文档重新运行并继续更新项目。
