# 行业景气度多因子轮动项目：面试讲解版

## 一句话介绍

我研究了一套基于==申万一级行业指数和动态龙头股池==的日频行业轮动策略。
完整参与了==数据清洗、龙头股筛选、量价因子构建、行业景气度建模、IC 分析、多因子组合、交易回测及对冲评估==的全过程。

策略的核心思想是：
- **短中期动量因子** 负责捕捉行业轮动节奏；
- **行业景气度因子** 负责提供更低频、更稳定的基本面趋势信号；
- 最终形成 **“情绪/动量 + 行业景气度”** 的组合信号，在 2018-07-01 至 2023-12-31 的样本中表现出较好的稳定性。

## 1. 项目背景

这个项目要解决的核心问题是：行业轮动既受短期交易情绪影响，也受中长期产业景气变化影响。如果只用行业指数，行业内部的信息表达不够充分；如果只用个股，又容易偏离行业配置主线；如果只用量价信号，策略还容易受到短期噪音影响。

因此，我把研究对象扩展为“行业指数 + 动态龙头股”，并同时构建动量和行业景气度两类信号。

## 2. 我的工作内容

我主要负责这套策略的数据清洗、动态龙头股筛选、量价因子构建、行业景气度建模、IC 分析、多因子组合、交易回测和对冲评估。

整个工作不是只做一个因子，而是把研究对象、数据、信号、组合和回测连成一套完整流程。

## 3. 核心研究方法

第一步是构建研究对象。

我使用申万一级行业指数表达行业层面的变化，同时每天用向前约 6 个月的数据动态筛选行业龙头股。筛选时先要求数据覆盖率不低于 90%，然后结合行业权重、自由流通市值和流动性生成候选池，再利用 Tracking Error 和与行业指数收益的相关性选择行业内 Top-5。

如果某个行业当天没有满足条件的股票，我会用行业平均权重最高的前 5 只股票等权合成捏合股，避免行业样本中断。

第二步是构建两类因子。

- 动量因子固定使用 5、20、60、120 和 252 日窗口：短期基础动量直接计算累计收益，中长期基础动量跳过最近 20 日；此外还计算基础动量的截面 Rank 和 Z-score、日收益排名持续性的 Rank Momentum、累计收益相对价格路径长度的 Smooth Momentum，以及价格区间位置因子。
- 景气度因子来自 Wind EDB 的行业中观指标。针对累计值、比率、价格和指数类数据分别处理，并按照数据更新日向后填充，同时考虑产业链传导滞后。之后按“行业 × 指标”计算 TS-IC，判断方向、剔除低信息指标并等权聚合。

第三步是组合和回测。

我先对筛选后的动量因子等权聚合，再加入由参数 $\lambda$ 控制的景气度信号。原始研究通过网格搜索比较 Sharpe 和稳定性，最终记录使用 $\lambda=0.8$。交易层面每天对候选池打分，选择 TopK 等权持有，并按换手率扣除成本。

## 4. 遇到的问题

项目中主要遇到四类问题：

1. 行业指数无法充分表达行业内部结构；
2. 固定龙头名单会产生时点失真，部分行业还会出现合格股票缺失；
3. 周频、月频景气数据与日频交易数据难以直接对齐，并存在信息前视风险；
4. 行业横截面规模较小、行业间相关性较高，动量因子的 CS-IC 不容易很高。

## 5. 解决方案

- 使用动态龙头股池补充行业内部信息，同时通过代表性评价保持行业轮动主线；
- 设计捏合股作为缺失行业的兜底机制，保持样本连续；
- 按实际更新日处理景气指标，向后填充到交易日，并按照价值链位置考虑传导滞后；
- 不只用单一 IC 判断动量因子，而是结合横截面 IC、纯多头回测和因子相关性共同筛选；
- 将景气度作为 tilt 融入排序，而不是用硬 gate 直接排除行业，使组合调整更平滑。

## 6. 项目成果

原始研究结论是：纯动量策略能够捕捉一定的行业轮动节奏，但稳定性一般；加入景气度信号后，策略收益、波动、Sharpe 和回撤表现更均衡。对冲宽基指数后仍保留一部分有效超额，因此原文将策略总结为弱 Beta、偏 Alpha 的行业轮动策略。

我认为这个项目最重要的成果，不只是得到一个组合信号，而是建立了一套从研究对象构建、低频数据处理、因子筛选、多因子组合到成本和对冲评价的完整研究框架。
