# Report

## 模块定位

本目录保存行业景气度多因子轮动项目的最终展示材料。报告强调研究目标、方法框架、个人工作、核心贡献与结果总结，不作为日常研究笔记或技术细节仓库。

## 报告文件

- [[项目总结报告|项目总结报告]]：完整项目展示版本，串联研究背景、研究对象、因子体系、组合逻辑、回测框架与原始研究结论。
- [[面试讲解版|面试讲解版]]：面向面试场景的 3–5 分钟项目介绍，突出个人工作、研究方法、问题解决与项目成果。

## 内容边界

本目录不保存：

- 原始数据、源代码或运行缓存；
- 因子公式和参数测试的全部技术细节；
- 回测程序与完整结果文件；
- 缺少项目证据支持的新结论或新数据。

详细研究内容分别由以下模块管理：

- 因子定义与构造：[[../03_Factors/README|Factors]]
- 回测设计与参数：[[../04_Backtest/README|Backtest]]
- 实验过程与结论：[[../06_Experiment/experiment_log|Experiment Log]]

## 证据状态

当前报告基于最初的项目 Markdown 整理。原始材料包含定性的回测结论，但未附完整指标表、净值图和实验记录；报告已保留原始结论并标注其证据状态，不将其表述为本次整理重新验证的结果。
