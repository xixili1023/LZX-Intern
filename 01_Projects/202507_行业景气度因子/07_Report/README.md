# Report

## 文件夹用途

将完整研究过程整理为适合复核、实习汇报和面试讲解的最终输出。

## 应该存放什么

- `完整研究报告.md`：完整问题、数据、方法、结果、局限与复现说明
- `实习汇报版.md`：面向实习场景的目标、工作、贡献和成果摘要
- `面试讲解版.md`：面向口头讲解的问题、挑战、决策、结果与反思
- 项目内报告所需的小型图表索引和版本说明

## 不应该存放什么

- 未经研究文档、实验记录、回测结果或代码版本支持的结论
- 大型原始数据、源代码或运行缓存
- 与项目无关的通用面试学习笔记
- 只有最终数字、缺少方法和限制的展示材料

## 与其他模块的关系

- 从 [[00_Project_Profile/README|Project Profile]] 获取背景与个人贡献。
- 从 [[01_Research/README|Research]] 获取研究逻辑与方法。
- 引用 [[02_Data/README|Data]]、[[03_Factors/README|Factors]]、[[04_Backtest/README|Backtest]]、[[05_Code/README|Code]] 和 [[06_Experiment/README|Experiment]] 的证据。
- 引用来源由 [[08_Reference/README|Reference]] 管理。
- 完整研究报告、实习汇报、面试材料和研究展示版本均保留在本模块，不再复制到独立的顶层报告目录。
- 通用输出说明可参考 [[03_Templates/Research_Report_Template/Output_Guides/README|Output Guides]]。
