# 当前任务

本页由 Tasks 自动汇总 `01_Projects` 下尚未完成的复选框任务。任务仍保存在其所属项目文档中，本页只提供统一视图。

## 项目任务汇总

```tasks
not done
path includes 01_Projects
group by function task.file.path.split("/")[1]
sort by priority
sort by due
sort by scheduled
```

## 统一 TODO 格式

最小格式：

```markdown
- [ ] 完成一个可验证的动作
```

需要安排日期时：

```markdown
- [ ] 补充数据字段字典 ⏳ 2026-08-01 📅 2026-08-03
```

- `⏳`：计划开始或处理日期。
- `📅`：最晚完成日期。
- 任务描述使用“动词 + 可交付结果”，避免只写“数据”“因子”等模糊名词。

任务不需要添加 `#task`。Tasks 直接根据 `- [ ]` 复选框识别任务。

状态统一为：

```markdown
- [ ] 待办
- [/] 进行中
- [x] 已完成
- [-] 已取消
```

完成任务时直接在本页或原项目文档中勾选；Tasks 会回写同一个 Markdown 源任务。

## 推荐存放位置

- 项目阶段任务：`01_Projects/<项目>/PROJECT_STATUS.md`
- 实验后续行动：`01_Projects/<项目>/06_Experiment/*.md`
- 数据、因子、回测文档中的局部任务：保留在对应文档附近

研究结论、方法说明和数据定义不是任务，不应写成复选框。
