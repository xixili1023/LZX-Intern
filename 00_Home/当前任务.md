本页自动汇总各项目的阶段进展，便于查看已经完成的里程碑、当前正在推进的工作和下一阶段计划。

任务源仅包括：

- `01_Projects/<项目>/PROJECT_STATUS.md`
- `01_Projects/<项目>/<编号>_Experiment/*.md`

本页只负责展示。项目状态和任务内容应在所属项目源文件中维护。

## 任务条规范

任务条用于展示研究进展：

```markdown
- [x] 完成历史数据资产盘点并记录来源
- [/] 建立替代指标映射与覆盖率统计
- [ ] 复现代表性行业的 TS-IC 结果
- [-] 取消缺少可靠数据来源的指标
```

统一状态：

```markdown
- [ ] 下一阶段或待验证
- [/] 正在进行
- [x] 已完成
- [-] 已取消
```

编写要求：

- 使用“动作 + 可交付结果”描述；
- 已完成事项应有文档、代码、实验或结果证据；
- 进行中事项只保留当前真正推进的重点；
- 下一阶段事项应足以说明后续研究路径；
- 不记录个人每日安排或与项目交付无关的事项；
- 研究结论、方法说明和数据定义不写成复选框。
