# Home

`00_Home` 是 Personal Quant Research Portfolio 的 Obsidian 导航层，只保存索引、地图和维护记录，不存放具体项目内容。

## 导航入口

- [[00_Home/首页|首页]]：整个研究数据库的主入口
- [[00_Home/项目索引|项目索引]]：浏览 `01_Projects` 中的项目
- [[00_Home/研究地图|研究地图]]：按研究方向连接项目、知识与资产
- [[00_Home/技能树|技能树]]：整理长期能力结构
- [[00_Home/更新日志|更新日志]]：记录数据库架构和重要维护变化

建议在 Obsidian 中将 [[00_Home/首页|首页]] 添加到书签或设为常用入口。
