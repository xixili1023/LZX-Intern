# Reference

## 文件夹用途

管理本项目专属的论文、资料、数据文档、链接和引用笔记，为研究方法和结论提供依据。

## 应该存放什么

- 项目专属参考文献清单与引用信息
- 论文、资料和数据文档的 Markdown 摘要
- 关键词、阅读状态和与研究模块的双向链接
- 允许版本管理的小型附件或合法来源链接

## 不应该存放什么

- 跨项目通用资料；应进入 [[02_Assets/References/README|Public References]]
- 未经许可上传的版权材料
- 体积过大的论文附件或数据包
- 没有来源信息、无法引用的零散文件

## 与其他模块的关系

- 为 [[01_Research/README|Research]] 的背景、方法和假设提供依据。
- 为 [[02_Data/README|Data]] 记录数据文档与口径来源。
- 为 [[03_Factors/README|Factors]] 和 [[04_Backtest/README|Backtest]] 记录方法参考。
- [[07_Report/README|Report]] 的参考资料应能够回链到本模块。
