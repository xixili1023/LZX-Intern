## 管理原则

- 原始研究过程和完整证据链保留在 `01_Projects`。
- 具体输出保存在对应项目的 `07_Report`，本目录只提供通用说明。
- 每份项目输出应链接回来源项目的研究记录，避免结论与证据脱节。
