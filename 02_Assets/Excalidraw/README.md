# Excalidraw 绘图规范

本目录保存跨项目可复用或需要在多篇文档中引用的 Excalidraw 源文件。项目专属图也可以放在这里，但必须通过文件名或子目录明确所属项目。

## 适合绘图的内容

### 研究框架图

- 研究问题、子问题和验证步骤之间的关系
- 数据、因子、回测、实验与报告之间的证据链
- 多个研究假设的并列或依赖关系

### 模型流程图

- 特征输入、训练、验证、预测和信号生成流程
- 样本内、样本外和滚动验证的时间顺序
- 数据泄漏检查与模型评价位置

### 因子逻辑图

- 原始变量到因子值的转换链路
- 多因子组合、权重和约束关系
- 因子经济逻辑与可检验假设之间的对应关系

### 回测流程图

- 信号时点、下单时点、成交时点和持仓更新
- 交易成本、风控、基准与绩效计算
- 数据输入、策略配置和结果产物之间的关系

## 不建议绘图的内容

- 可以用一段话或短列表清楚说明的单一步骤
- 参数表、数据字段表和实验结果表
- 需要精确引用的研究结论
- 只是装饰、没有进入项目文档的孤立图片

## 使用规则

1. 先在 Markdown 中写清研究逻辑，再决定是否需要图。
2. 图中节点优先使用 `[[Obsidian 双向链接]]` 指向数据、因子、回测或实验文档。
3. 每张正式图应嵌入至少一篇项目 Markdown 文档，不单独充当结论来源。
4. Excalidraw 源文件保留可编辑性；只有报告或 GitHub 展示需要时才导出 SVG 或 PNG。
5. 不批量生成示意图，不为每篇笔记创建配图。

## 命名建议

```text
<项目目录>_<图类型>_<主题>.excalidraw.md
```

例如：

```text
202507_行业景气度因子_研究框架_信号组合.excalidraw.md
```
